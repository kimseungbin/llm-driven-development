Acceptance criteria (from intent rev 2abca27)
  • A gate view rendered in Korean shows every fixed label, badge, button, and status line in Korean.
  • A gate view rendered without choosing a language is unchanged from today.
  • Authored text (the request, problem, criteria, questions, and answers) appears exactly as written in every language.
  • An approval sent from a Korean view names the same gate and rev, and is accepted the same way, as one sent from an English view.
  • Adding another language takes only a new set of translations, with no change to any view (Q2).
  • The language is each person's own choice: one person choosing a language never changes what anyone else sees (Q3).
  • A person's language choice applies in every repo they work in, without setting it per repo (Q5).
  • When a request is written in Korean, the agent-written fields of its intent and plan are in Korean too (Q4).
